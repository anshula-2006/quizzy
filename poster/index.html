Abstract / Summary

Quizzy is an AI-powered learning and assessment platform that automates quiz creation from topics, PDF documents, and web URLs. It helps students practice faster with customizable quizzes, instant evaluation, AI-generated explanations, flashcards, progress analytics, leaderboard ranking, and Brain Lab activities. Teachers can monitor real quiz attempts, topic performance, accuracy, and recent learner activity through a dedicated dashboard. The system makes learning more personalized, measurable, and engaging.
